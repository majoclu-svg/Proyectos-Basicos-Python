# 📝 Analizador de Texto en Python

Un script interactivo en Python que recibe un texto del usuario y realiza un análisis rápido de su contenido. Este proyecto demuestra el dominio de los fundamentos de programación, manipulación de cadenas de texto (strings) y estructuras de datos.

## 🚀 Características Principales

El programa solicita al usuario un párrafo y tres letras de su elección para realizar el siguiente análisis:
*   **Conteo de caracteres:** Calcula cuántas veces aparece cada una de las letras elegidas.
*   **Conteo de palabras:** Determina la longitud total del texto en palabras.
*   **Indexación:** Identifica el primer y último carácter del texto ingresado.
*   **Manipulación de listas:** Invierte el orden de las palabras y genera un nuevo texto.
*   **Búsqueda booleana:** Verifica la existencia de una palabra clave específica (en este caso, "Python") utilizando diccionarios para mostrar respuestas amigables al usuario.

## 🛠️ Tecnologías Utilizadas

*   **Lenguaje:** Python 3
*   **Conceptos aplicados:** Ciclos `for`, Listas por comprensión (List Comprehensions), Diccionarios, Métodos de Strings, y validación de datos.

# 🎮 Juego: Adivina el Número

Un juego interactivo de consola desarrollado en Python. El jugador debe adivinar un número secreto entre 1 y 100 en un máximo de 8 intentos, recibiendo pistas lógicas si el número ingresado es mayor o menor.

Este proyecto fue creado para consolidar fundamentos clave de programación, demostrando el uso de control de flujo, manejo de variables, interacción con el usuario y la implementación de librerías estándar.

## 🚀 Características

*   **Lógica de rangos:** Generación de números aleatorios utilizando la librería `random`.
*   **Validación de datos:** El sistema alerta al usuario si ingresa un número fuera del rango permitido (1 al 100).
*   **Gestión de estado:** Sistema de contador de intentos con un límite estricto que finaliza la ejecución al llegar a 8.
*   **Feedback dinámico:** Interfaz de texto que guía al jugador paso a paso.

## 🛠️ Tecnologías utilizadas

*   **Lenguaje:** Python 3.x
